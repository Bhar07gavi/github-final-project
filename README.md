# Simple Interest Calculator

A lightweight Bash command-line tool that calculates simple interest based on user-provided inputs: principal amount, rate of interest, and time period.

## Project Details

- **Project Name:** Simple Interest Calculator
- **Description:** This project is a Bash shell script that prompts the user for the principal amount, annual interest rate, and time period (in years), then calculates and displays the simple interest using the formula: `Simple Interest = (Principal x Rate x Time) / 100`.
- **Language:** Bash (Shell Script)
- **Author:** <Your Name>
- **License:** Apache License 2.0 (see [LICENSE](./LICENSE))

## How to Use

```bash
chmod +x simple-interest.sh
./simple-interest.sh
```

You will be prompted to enter:
1. Principal amount
2. Rate of interest (annual, in %)
3. Time period (in years)

The script will then output the calculated simple interest.
